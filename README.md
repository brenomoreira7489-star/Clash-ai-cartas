🏆 Clash AI Pro Ultimate

Assistente inteligente de estratégia para Clash Royale

O Clash AI Pro Ultimate é um projeto desenvolvido em Python com o objetivo de auxiliar jogadores de Clash Royale na análise de cartas, estratégias de defesa, estimativa de elixir e acompanhamento das partidas.

O projeto está em desenvolvimento e busca evoluir para um treinador estratégico com reconhecimento visual e orientações por voz.

---

🚀 Funcionalidades

- 🃏 Consulta do deck do jogador.
- 🔎 Reconhecimento aproximado dos nomes das cartas.
- ⚔️ Análise de cartas adversárias.
- 🛡️ Recomendações de defesa e ataque.
- 🔄 Registro e acompanhamento do ciclo adversário.
- ⚡ Estimativa manual de elixir.
- 🎙️ Orientações por voz.
- 📊 Histórico e estatísticas de partidas.

🛠️ Tecnologias utilizadas

- Python 3
- Termux
- Android
- JSON
- Text-to-Speech (TTS)

📲 Como executar

1. Instale o Python 3.
2. Abra o Termux.
3. Clone o repositório:

git clone https://github.com/brenomoreira7489-star/Clash-ai-cartas.git

4. Entre na pasta:

cd Clash-ai-cartas

5. Execute:

python clash_ai_pro.py

🎯 Objetivo do projeto

Desenvolver um assistente estratégico capaz de analisar situações de jogo, reconhecer cartas, sugerir posicionamentos e fornecer orientações em tempo real.
